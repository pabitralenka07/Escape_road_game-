## 📖 About The Game

**Escape Road** puts you behind the wheel as a bank-heist getaway driver trying to escape an relentless, city-wide police chase. The longer you survive, the more intense the pursuit becomes—bringing in squad cars, SWAT trucks, helicopters, and heavy roadblocks. Dodge traffic, take sharp turns, collect cash, and see how long you can last before getting busted!

---

## ✨ Features

- ⚡ **Instant Play**: No downloads or installs required—runs directly in modern web browsers.
- 🚓 **Escalating Police Pursuit**: Face patrol cruisers, interceptors, armored SWAT vans, and tactical obstacles.
- 🏙️ **Dynamic City Environment**: Navigate intersections, buildings, highways, and civilian traffic.
- 📱 **Cross-Platform Support**: Optimized for desktop browsers with responsive canvas scaling.
- 🎯 **High Score Chasing**: Collect money to unlock new vehicles and set unbeatable personal bests.

## 🚀 Quick Start (Play Locally)

You can run the game locally using any simple web server:

### 1. Clone the repository
```bash
git clone https://github.com/pabitralenka07/Escape_road_game-.git
cd Escape_road_game-
```

### 2. Launch a local web server
Using Python 3:
```bash
python3 -m http.server 8000
```
Or using Node.js:
```bash
npx serve .
```

### 3. Open in Browser
Visit `http://localhost:8000` in Google Chrome, Firefox, Brave, or Edge.

## 🌐 Deploy to GitHub Pages (One-Click)

1. Go to your repository on GitHub: `https://github.com/pabitralenka07/Escape_road_game-`
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your game will be live at:
   ```
   https://pabitralenka07.github.io/Escape_road_game-/
   ```
